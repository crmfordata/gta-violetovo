# Grand Theft ФИОЛЕТОВО

Лоу-поли 3D-прототип в духе GTA Vice City: русская деревня в фиолетовой закатной палитре. Один самодостаточный HTML-файл, Three.js r128 через CDN, вся геометрия — процедурная (боксы, цилиндры, конусы, сферы).

## Задание
Дойти от точки А до лошади, сесть на неё (E) и доскакать до точки Б. По прибытии — «Задание выполнено!».

## Управление
- **WASD / стрелки** — движение (относительно камеры)
- **Мышь** (зажать и вести) или **Q / E** (удерживать) — камера
- **E** — сесть на лошадь / слезть

## Что внутри
- Третья-лицо камера с raycast-защитой от стен
- Игрок и лошадь из боксов, анимация шага/галопа
- Деревня: дома с тёплыми окнами, церковь с куполом, деревья, заборы, колодец, стога
- AABB-коллизии со зданиями и деревьями
- Закатное небо-градиент, туман, тёплый направленный свет
- Процедурные звуки через Web Audio API: шаги, галоп, победный джингл

## Запуск
Открыть `index.html` в браузере — и всё. Никаких сборок и серверов.
